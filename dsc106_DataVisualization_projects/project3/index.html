Methodology and design rationale

Data source and transformations

Monthly near-surface air temperature (tas) was extracted from the NOAA/Google public CMIP6 Zarr catalog for NCAR CESM2 ensemble member r4i1p1f1. Monthly values were weighted by days per month and aggregated to annual means at the nearest model grid cell for nine locations.

Each series is expressed as an anomaly from that location's 1981-2010 historical mean. The comparison, map, and rank summaries use a five-year mean ending at the selected horizon to reduce single-year noise.

Interaction and visual encoding rationale

The line chart uses shared time and temperature axes for trajectory comparison. The projected point map adds spatial context without overclaiming geographic precision from only nine sampled model grid cells. The ranking chart answers "where is warming greatest?" while the spread chart shows how emissions choices diverge.

Interactions are coordinated through one state object: selected location, focus pathway, visible pathways, threshold, horizon, metric, map zoom, insight preset, and playback status. URL parameters encode shareable filters without requiring a backend.

Limitations, performance, and accessibility

This explorer shows one climate model and one ensemble member, not a multi-model uncertainty range. Locations are nearest grid cells rather than station observations. SVG rendering is appropriate for this compact dataset; grouped summaries are cached and redraws are scheduled with requestAnimationFrame.

The dashboard uses keyboard-focusable controls, direct labels, visible selected states, accessible color contrast against light and dark themes, and text summaries for the current filtered state.
